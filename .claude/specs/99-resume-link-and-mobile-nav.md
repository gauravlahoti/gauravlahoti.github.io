# Spec 99: Resume link on standalone pages, and nav logo hardening

## Problem
- The Resume link on `/live-agents/` went to `/#` instead of the PDF. The same bug was on all four `/ai-labs/` pages.
- Two stale layers caused it, both left over from before the PDF link existed: `<a href="/#" data-resume-trigger-agents>` in the markup, and a click handler in each page's JS that called `preventDefault()` and set `window.location.href = "/#"`.
- A review also asked for a "View resume" button on mobile and a fix for a bracket graphic overlapping the name.

## Decisions
- Resume links now use the home page's form: `href="/resume.pdf" target="_blank" rel="noopener noreferrer"`, in both the nav and the drawer. The handlers are deleted.
- No new mobile button. On phones the Resume link is in the hamburger drawer, and the drawer link now works on every page.
- The "bracket" is taken to be the L-shaped GL logo beside the name in the nav pill. It did not overlap the name at 320, 360 or 390px, or at 150% and 200% text size. The logo got `flex: none` in `layout.css` so a tight row can never squeeze it into the name. This is defensive, not a confirmed fix.
- Insights pages (generated by `scripts/gen-post-pages.mjs`) have no Resume link. Left as is.

## Files
- `live-agents/index.html`, `ai-labs/index.html`, `ai-labs/{mcp-lab,agent-ready,engineering-loops}/index.html`: Resume links.
- `assets/js/{agents-page,ai-concepts-page,mcp-lab-page,webmcp-lab-page,engineering-loops-page}.js`: handlers removed.
- `assets/css/layout.css`: `.nav-brand::before { flex: none }`.
- `tests/nav-resume.test.mjs`: every Resume link points at `/resume.pdf`, no `data-resume-trigger` left in pages or scripts.

## Definition of done
- [x] Resume in the nav and drawer opens `/resume.pdf` on all five standalone pages and the home page.
- [x] `node --test 'tests/**/*.test.mjs'` passes.
- [x] Logo and name boxes do not intersect at 320px with text at 100%, 150% and 200%.
- [ ] After deploy, `https://gauravlahoti.dev/resume.pdf` opens from each page.

## Known, not fixed
- Locally `/resume.pdf` is a 404. The deploy workflow copies `assets/img/resume.pdf` to that path, so it only exists on the published site.
- On `/live-agents/` below about 390px wide, `.agent-card` is 375px wide and the page scrolls sideways. Present before this spec and unrelated to the nav.
